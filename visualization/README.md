# Visualization Module

## Purpose

The `visualization/` directory provides modular plotting routines and visual analytics tools built on Matplotlib to graphically illustrate the quantum mechanics and statistical outcomes of the BB84 protocol.

## Planned Visualizations

1. **QBER vs. Noise Probability**: Curves plotting Quantum Bit Error Rate against varying channel noise parameters with theoretical expectation bounds.
2. **Eavesdropping Detection Bounds**: Visualizing QBER distributions under intercept-resend attack vs. noise thresholds (e.g., highlighting the classical 11% Shor-Preskill / CSS code threshold).
3. **Key Sifting Statistics**: Bar charts and histograms depicting raw key length, basis matching efficiency, sifted key length, and final key length after error reconciliation.
4. **Quantum State and Circuit Representations**: Exporting and visualizing quantum circuit diagrams and Bloch sphere representations for BB84 preparation and measurement states.

## Guidelines

- Keep visualization code strictly decoupled from quantum protocol execution and simulation backends.
- Visualizations should accept Pandas DataFrames or NumPy arrays generated by the `experiments/` scripts.
- Generated figures can be displayed interactively or saved to high-resolution formats (`.png`, `.pdf`) inside `results/`.
